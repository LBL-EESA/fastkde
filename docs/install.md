# Installation

Install fastKDE using pip:

```bash
python -m pip install fastkde
```

To get set up with a development version, clone the repository and use [uv](https://docs.astral.sh/uv/) to install:

```bash
git clone https://github.com/LBL-EESA/fastkde.git
cd fastkde
uv sync
uv pip install -e .
```
